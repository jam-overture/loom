## Decisions taken that were not specified

**To continue an open branch rather than cut a new one.** The brief's step 3 says
*branch off `main`, never stack*. The maintainer's 28 August finding says
*before starting a unit, check whether you already have an open pull request; if
you do, continue it rather than branching again*. Read literally those disagree.
I followed the finding, because it is newer, it is the maintainer's own, and it
was written about this exact cost. The previous run of this lane made the same
call and edited `docs/routines.md` step 3 to say so; that edit is on this branch
and is still the maintainer's to veto.

**To close a finding by editing an entry filed by another lane.** `Loom docs`
filed the `loom init` collision; the closure was already recorded on 29 August by
this lane, from a branch that had not merged, and that entry said in terms that
"whoever merges both will find the two halves". Both are on `main` now, so the
original entry's Status was edited to point at #195 and 0101. Verified in
`src/cli/plan.ts` and `src/cli/namespace.ts` rather than inferred from the
closure entry — `HOST_NAMESPACE` is `"app"`, so the scaffold writes `app.page`
and cannot collide with the starter library's `loom.page`.

**Not to write the per-lane numbering convention**, though six runs have now
asked for it and it would have been the easiest unit available. A routine may not
write the governance it is bound by, and 0097 says explicitly that the convention
belongs to whoever writes `docs/routines.md`. What this run could add is a fact,
and it did — see below.

## Findings filed

- **A per-lane number range is the fix six runs have asked for, and 0097's index
  is why it cannot be a wide one.** Owned by the maintainer. `renderIndex` writes
  a row for every unclaimed number below the highest, so block ranges of a
  hundred per lane would put roughly **seven hundred** `*No record on this
  branch*` rows into the index and seven hundred `note:` lines into every run of
  every lane. The dense alternative — each lane taking the numbers congruent to
  its own index modulo seven — cannot collide either and keeps the holes to at
  most six at a time. Filed as a constraint on a decision that is the
  maintainer's, not as a request to reverse 0097.

# Getting started

Loom lets somebody ask a page to change in plain words, and decides whether to
let the change through. This section is the shortest way to watch that happen on
your own machine.

You need Node and a terminal. You do **not** need an AI model, an API key or a
database for anything in this section: the examples on these pages are driven by
a fixed set of asks rather than by a model, so the propose box beside each one
works in your browser as you read.

## What you have at the end of them

You have a page that is data rather than markup: a small document listing
elements, their text and their props, and one function that turns it into React.

Somebody can ask that page for a change in a sentence, and the rules you wrote
decide what happens to it. The change is applied, or it is set aside for a person
to answer, or it is refused with a reason you can read. In all three cases you
can say exactly why.
